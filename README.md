# angularity-fw
A heavily modded CFW for Flipper Zero based on Momentum FW MNTM-012

# A few features:

Sound packs

Custom icons

Stealth/Dummy mode

2 new menu styles

and more

# Flashing
Flash the .tgz file using qFlipper or extract the .tgz and put the folder on your Flipper, then in the file browser, click **update.fuf**
