Features

Everything Angularity adds on top of Momentum, and how to use it. Menus are under Angularity (the app in the main menu) unless noted.

Configurable Control Center

The Control Center is the tile menu on the Desktop. Angularity lets you decide what each of the 8 tiles does.

  • Where: Angularity → Interface → Control Center. Pick an action for each slot, or reset to the default layout.
  • Actions: Left-handed, Settings, Dark mode, Lock, Bluetooth, Angularity, Dummy mode, Computer Mode, Pseudo-Off, Stealth, Diagnostics, SD Health, Next profile, Standby.

Pseudo-Off

Like turning the Flipper off, but it keeps charging. The screen goes dark, the running app is asked to close, the Flipper locks, Bluetooth stops advertising and OTG power is cut. Hold OK to wake it.

  • Start it: Settings → Power → Pseudo-Off, a Control Center tile, or a Desktop keybind named “Pseudo-Off”.
  • Good to know: it is not saved across a reboot, services stay resident, and waking lands on the lock screen (PIN if set).

Theft alarm

Sounds an alarm, flashes the LED and/or locks the Flipper when the trigger fires.

  • Triggers: unplugging the charger, a GPIO “pull” wire, or a GPIO “tether” wire.
  • Safe by design: unlocking the Flipper silences the alarm, and GPIO triggers only fire when a healthy connection breaks — so a wire already in the wrong state can’t lock you out.
  • Where: Angularity → Misc → Power. Includes quiet hours, a security log and battery health.

Profiles

Three slots — Home, Work, Travel — that remember screen brightness, volume, LED, vibration, Bluetooth, dark mode and the theft alarm.

  • Where: Angularity → Misc → Profiles to save or apply; add the “Next profile” Control Center tile to cycle through saved ones.

Standby

A dimmed bedside/desk display. Open it from Apps → Tools → Standby or add its Control Center tile. Left/Right change pages, Up/Down set the idle brightness, OK opens the menu.

  • Pages: clock, weather (3-day outlook), calendar, and JWLink watch data.
  • With the WiFi Devboard: weather from Open-Meteo (no account), clock sync from the internet, and a weekly check for a newer firmware. Without it, the clock and calendar still work and the last weather is remembered.
  • JWLink: shows battery, steps, heart rate and upcoming events from your PineTime watch app, delivered by the qAngularity phone app.

Angularity Update (over WiFi)

Update the firmware from the Flipper itself — no phone or computer. Needs a WiFi Devboard running FlipperHTTP firmware.

  • WiFi setup: scan, pick or type a network, enter the password; it connects and checks that the internet works.
  • Check and install: downloads in resumable chunks, verifies the SHA-256, unpacks to the SD card and hands over to the system updater.
  • Auto-check: a quiet check when you open the app shows “Update available” in its menu.
  • Rollback: keeps the last few unpacked packages on the SD card and can download the previous release.

A 13 MB package takes about 20 minutes over the devboard’s serial link. Needs roughly 2.2× the package size free on the SD card and at least 30% battery.

App Permissions opt-in

When switched on, launching a third-party app that uses sensitive hardware asks first: Deny, Once or Always. Answers are remembered per app.

  • Kinds: Radio (Sub-GHz), NFC, RFID/iButton, IR, GPIO, USB, Bluetooth — each has its own “ask” switch.
  • Trusted: apps that ship with the firmware (Sub-GHz, NFC, Infrared, Settings, Passport…) are never prompted.
  • Where: Angularity → Misc → App Permissions.

This is a prompt based on what an app links against, not a sandbox. It tells you what an app can reach; it does not stop a determined malicious app.

Diagnostics & SD Health

Diagnostics (Apps → Tools): live battery voltage/current/health, a button test, speaker/vibration/LED test, system info and the last crash message.

SD Health (Apps → Tools): card info, a speed test, a 16 or 64 MB write-and-verify surface test, and a folder integrity scan.

SD Health tests free space and reads folder structure. It cannot repair a damaged card — if it reports problems, back up and reformat on a computer.

Screenshots off by default

Hold two keys for about a second and the current screen is saved as a BMP in /screenshots on the SD card (4× scaled, Flipper orange).

  • Turn it on: Angularity → Misc → Screenshot, then choose the key pair (Left+Right, Up+Down, Left+OK or Right+OK). Nothing hooks in until you enable it.

WiFi Devboard apps

Apps that use the WiFi Devboard (FlipperHTTP firmware): Flip Browser (text-mode web browser), Net Audio Player (plays a WAV/MP3 URL through the speaker), Claude Chat (talks to the Anthropic API with your own key), Spotify Remote and DolphinMusic.

Computer Mode experimental turns a custom ESP32 firmware into a USB keyboard/mouse host for a simple notepad — it replaces FlipperHTTP on the board and depends on the devboard’s USB port supporting host mode, which is unverified.

And more

  • Looks & sound: the “Angularity” Triforce-style and Wheel menus, sound packs, icon packs, per-app open sounds.
  • Dummy mode with real minigames, a Dolphin XP and streak system shown on the Passport.
  • Security extras: Find My Flipper, lock-screen status icons, GPIO mirror, opt-in NFC tag unlock, Shortcuts (trigger/action automation).
  • USB Audio peripheral mode.

Inherited from Momentum: the full app catalog, asset packs, and everything else the base firmware offers.
