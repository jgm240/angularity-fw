Install

Angularity FW installs like any Flipper firmware update: a single .tgz package. Always use the full package — the extra apps live on the SD card and are only copied by a full update.

Before you start: back up your SD card (or at least /ext/apps_data and your saved files), charge the Flipper to at least 30%, and keep a computer with qFlipper available in case you need to recover.

Method 1: qFlipper (recommended)

  1. Download the latest .tgz from the Downloads page. Do not unpack it.
  2. Connect the Flipper to your computer with USB and open qFlipper.
  3. Use qFlipper’s option to install firmware from a file and pick the .tgz.
  4. Wait for the Flipper to restart and finish updating. Don’t unplug it.

Method 2: from the SD card

  1. Extract the .tgz on your computer. You get a folder named like f7-update-AngularityFW-releaseNN.
  2. Copy that folder to /ext/update on the Flipper’s SD card.
  3. On the Flipper open Archive (or the file browser), go to /ext/update/…/, select update.fuf and choose Run.

Method 3: from the Flipper over WiFi

If you already run a recent Angularity FW and have a WiFi Devboard:

  1. Put FlipperHTTP firmware on the devboard (Apps → GPIO → ESP → ESP Flasher; firmware at jblanked/FlipperHTTP).
  2. Open Apps → Tools → Angularity Update → WiFi setup and connect to a 2.4 GHz network.
  3. Choose Check and install update. It downloads, verifies, unpacks and then offers to install.

From your phone

The qAngularity apps update the firmware over Bluetooth, the same way the official mobile app does. They are built from source for now — see the qAngularity repository for instructions.

After installing

  • The new apps appear under Apps → Tools (Standby, Diagnostics, SD Health, Angularity Update) and the Angularity settings under the Angularity app.
  • If apps are missing, the SD card wasn’t updated — this happens when only the firmware file is flashed. Install the full .tgz again.
  • To confirm a download wasn’t corrupted, compare its SHA-256 (shown on the Downloads page) with shasum -a 256 file.tgz.

If something goes wrong

  • The Flipper won’t start or an app crashes the system: reinstall a known-good release with qFlipper. If it can’t connect, put the Flipper in DFU mode and use qFlipper’s recovery — the official Flipper documentation explains how.
  • “App Not Found” on a tile or menu entry: the app file isn’t on the SD card. Install the full package.
  • Still stuck: open an issue with the release number and what the screen says.
